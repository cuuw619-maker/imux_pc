# Changelog

## 0.0.1 — 2026-09-19

- Rebuilt the launcher workspace and navigation from scratch.
- Added a responsive launch screen for compact and wide Windows layouts.
- Replaced the mock launch process with a real executable launch boundary.
- Kept the built-in native first-person world as the base-game fallback in the Windows launcher.
- Added an in-launcher changelog with the current version.
- Unified the Windows launcher around a 1920x1080 design canvas with proportional scaling.
- Aligned mouse hitboxes with the exact rendered layout and added F11 fullscreen.
- Added PerMonitorV2 DPI awareness to the native executable manifest and input mapping.
- Kept the release at 0.0.1 until the project owner explicitly approves the next version.

Versioning rule: do not increment the version until the current release is approved. Each approved release appends only its actual changes to this file and to the launcher changelog.
